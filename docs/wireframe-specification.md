# Wireframe Specification — APM Jambi

## 1. Public Layout Wireframe
- **Header / Navbar**: Brand Logo (left), Navigation Links (Center: Beranda, Tentang, Program, Berita, Galeri, Kontak), Action Button `Hubungi Kami` (Right, Crimson Red `#DC2626`). Mobile Hamburger toggle slide-out menu.
- **Hero Section**: Left-side title & APM tagline, description, CTA button `Jelajahi Program`, Right-side activity collage image frame.
- **Card Containers**: 3-column responsive grid on desktop, 1-column on mobile.
- **Footer Section**: Deep purple background (`#6B21A8`), logo, description, quick sitemap links, contact information, social links, copyright notice.

## 2. Admin Layout Wireframe
- **Sidebar**: Dark Royal Blue (`#1E3A8A`), APM Logo & Brand Name, Navigation Items (Dashboard, Berita, Galeri, Profil Organisasi, Kontak, Logout button).
- **Topbar**: Mobile sidebar toggle button, page header title, user indicator ("Admin APM Jambi").
- **Content Area**: Clean background (`#F8FAFC`), white card containers (`#FFFFFF`), shadow accents, statistical counters, search/filter bars, clean data tables with action buttons (Edit, Delete, View).
